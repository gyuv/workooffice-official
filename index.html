Architecture

Engineered like a ledger.

01

One source of truth

Every app talks to the same NestJS API; Postgres row-level security isolates each firm.

02

Offline first

Desktop and Android keep a local store and an outbox; field-level versions merge edits safely.

03

Every change audited

In the same transaction, on a hash-chained log.

04

Paise & IST

Statutory dates and prices come only from rule packs — never hard-coded.

05

Per-tenant secrets

Envelope keys; reveals need step-up auth and are audited.

06

Accessible

AA contrast in every theme and accent, keyboard-first, reduced-motion honoured.
